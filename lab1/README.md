## 2. 🎯 Что умеет этот калькулятор

В методичке написано 6 пунктов требований на 10 баллов:

1. **Базовая арифметика над вещественными (дробными) числами (5 баллов):**
   - Сложение `+`, вычитание `-`, умножение `*`, деление `/`.
   - Поддержка запятой/точки `.`, смена знака `+/-`, стирание последней цифры `⌫`, полная очистка `C` и очистка текущего ввода `CE`.
2. **Минимум 3 дополнительные операции (+1 балл):**
   - Корень `√x`, возведение в квадрат `x²`, обратное число `1/x`, проценты `%`, степень `x^y`, модуль `|x|`, факториал `n!`.
3. **3 тригонометрические + 3 логарифмические операции (+1 балл):**
   - Тригонометрия: `sin`, `cos`, `tan` (есть переключатель **DEG** (градусы) / **RAD** (радианы)).
   - Логарифмы: `log` (десятичный), `ln` (натуральный), `log2`, а также `10^x` и `exp` ($e^x$).
4. **Работа с памятью (+1 балл):**
   - Кнопки `MC` (стереть память), `MR` (вставить из памяти), `M+` (прибавить к памяти), `M-` (отнять из памяти), `MS` (сохранить в память).
   - Когда в памяти что-то есть, на экране загорается буква **M**.
5. **Обработка ошибок вычислений (+1 балл):**
   - Если делить на ноль — пишет `Eroare: Împărțire la zero!`.
   - Если извлекать корень из отрицательного — пишет `Eroare: Radical din număr negativ!`.
   - Программа **не вылетает с ошибкой**, а просто предупреждает тебя на экране. Нажатие `C` сбрасывает ошибку.
6. **Системы счисления (+1 балл):**
   - Режим **Programator (Baze)**. Сверху сразу показывается число в:
     - **HEX** (16-ричная)
     - **DEC** (10-тичная)
     - **OCT** (8-ричная)
     - **BIN** (двоичная)
   - Появляются кнопки шестнадцатеричных цифр `A`, `B`, `C`, `D`, `E`, `F`.

## 3. 💡 Как устроен код (ООП простыми словами)

Преподаватель обязательно спросит: *«Покажи мне 4 принципа ООП в твоей программе!»*  
Вот ответы, которые поймет любой и которые идеально соответствуют коду:

### 1. Инкапсуляция (Encapsulation)
> **Что это:** Мы прячем переменные внутри класса со словом `private`, чтобы никто снаружи не мог случайно их сломать или подделать. Доступ к ним даем только через методы.

**Где у нас в коде:**
Посмотри на файл `src/Memory.java`. Там переменные:
```java
private double memoryValue = 0.0;
private boolean hasValue = false;
```
Они `private`! Другие классы не могут написать `memory.memoryValue = 9999;`.  
Они обязаны вызывать специальные методы: `store()`, `add()`, `recall()`, `clear()`. Это и есть инкапсуляция.

---

### 2. Абстракция (Abstraction)
> **Что это:** Мы создаем общий шаблон (интерфейс или абстрактный класс), в котором говорим, ЧТО операция должна делать, но не пишем КАК именно она это делает.

**Где у нас в коде:**
Посмотри на файл `src/operations/BinaryOperation.java`:
```java
public abstract class BinaryOperation implements Operation {
    public abstract double calculate(double a, double b) throws Exception;
}
```
Здесь сказано: любая бинарная операция принимает два числа `a` и `b` и возвращает результат `double`. А как именно складывать или делить — решает каждый отдельный класс.

---

### 3. Наследование (Inheritance)
> **Что это:** Мы берем общий класс-родитель и создаем от него классы-дети через слово `extends`, чтобы не писать один и тот же код по 10 раз.

**Где у нас в коде:**
В папке `src/operations/`:
- `Addition extends BinaryOperation` (Сложение)
- `Subtraction extends BinaryOperation` (Вычитание)
- `Multiplication extends BinaryOperation` (Умножение)
- `Division extends BinaryOperation` (Деление)
- `SquareRoot extends UnaryOperation` (Корень)
- `Sinus extends UnaryOperation` (Синус)

Все они — дети базовых классов `BinaryOperation` или `UnaryOperation`.

---

### 4. Полиморфизм (Polymorphism)
> **Что это:** По-гречески «много форм». Это когда мы можем работать с разными операциями одинаково, не зная заранее, что именно нажал пользователь.

**Где у нас в коде:**
В файле `src/Calculator.java`:
У нас есть одна переменная:
```java
private BinaryOperation currentOperation;
```
Когда пользователь нажимает кнопку `+`, мы пишем:
```java
currentOperation = new Addition();
```
А когда нажимает кнопку `/`:
```java
currentOperation = new Division();
```
А когда пользователь нажал клавишу `=`, мы просто пишем:
```java
double result = currentOperation.calculate(firstNumber, secondNumber);
```
Нам **не нужно** писать 20 условий `if (нажали плюс) ... else if (нажали минус) ...`. Java сама знает, какую именно операцию вызвать! Это и есть полиморфизм.

## 4. 📂 Подробный разбор каждого файла

Структура папок очень простая:
```
lab1/
├── src/
│   ├── Main.java              # Запуск программы
│   ├── Calculator.java        # Окно калькулятора, кнопки и обработка кликов
│   ├── Memory.java            # Ячейка памяти (MC, MR, M+, M-, MS)
│   ├── BaseConverter.java     # Переводчик в HEX, BIN, OCT
│   ├── TestCalculator.java    # Тест без интерфейса
│   └── operations/            # Математические операции
│       ├── Operation.java        # Базовый интерфейс
│       ├── BinaryOperation.java  # Шаблон для двух чисел (a + b)
│       ├── UnaryOperation.java   # Шаблон для одного числа (корень, sin)
│       ├── Addition.java         # Сложение
│       ├── Subtraction.java      # Вычитание
│       ├── Multiplication.java   # Умножение
│       ├── Division.java         # Деление (с проверкой на 0)
│       ├── SquareRoot.java       # Корень (с проверкой на минус)
│       ├── Sinus.java            # Синус
│       ├── Cosinus.java          # Косинус
│       ├── Tangens.java          # Тангенс
│       ├── Logarithm.java        # Десятичный логарифм
│       ├── NaturalLog.java       # Натуральный логарифм (ln)
│       └── ... и другие операции
├── run.sh                     # Скрипт для запуска
└── README.md                  # Эта инструкция
```

### Как работает `Calculator.java`:
1. `public class Calculator extends JFrame implements ActionListener` — наследует окно `JFrame` и слушает нажатия кнопок `ActionListener`.
2. В методе `initUI()` создаются экран (`displayField`), надпись истории (`historyLabel`), выпадающий список для переключения режимов (`modeBox`) и кнопки.
3. В методе `actionPerformed(ActionEvent e)` мы смотрим, какая кнопка нажата:
   - Если цифра — дописываем в конец строки на экране.
   - Если знак операции (`+`, `-`, `*`, `/`) — запоминаем первое число и операцию.
   - Если `=` — считаем результат и выводим на экран.
   - Если память (`MS`, `MR` и т.д.) — вызываем методы объекта `Memory`.

## 5. 🎓 Шпаргалка для ответа преподавателю на защите

1. **Вопрос:** *Почему ты не написал весь калькулятор в одном файле `Main.java`?*  
   **Ответ:** Потому что это лабораторная работа по **Объектно-Ориентированному Программированию (ООП)**. Главная цель — разделить ответственность между объектами: окно отвечает за кнопки и отображение, классы операций — за математические вычисления, а класс `Memory` — за хранение числа в памяти.

2. **Вопрос:** *Что будет, если пользователь разделит на ноль?*  
   **Ответ:** В классе `Division.java` стоит проверка:
   ```java
   if (b == 0) {
       throw new Exception("Împărțire la zero!");
   }
   ```
   Калькулятор поймает это исключение через блок `try - catch` и выведет сообщение об ошибке на экран. Программа не упадет.

3. **Вопрос:** *Как калькулятор считает тригонометрию (в радианах или градусах)?*  
   **Ответ:** В научном режиме есть кнопка **DEG / RAD**. По умолчанию стоят градусы. Если выбраны градусы, мы переводим их в радианы с помощью `Math.toRadians(a)`, так как метод `Math.sin()` в стандартной Java всегда принимает радианы.

4. **Вопрос:** *Как работает перевод в шестнадцатеричную (HEX) и двоичную (BIN) системы?*  
   **Ответ:** В классе `BaseConverter.java` мы берем целую часть числа и вызываем методы Java `Long.toHexString(n).toUpperCase()` и `Long.toBinaryString(n)`.

## 6. 🛠️ Как добавить новую кнопку в калькулятор (за 3 шага)

Если преподаватель скажет: *«А добавь-ка сюда кнопку $x^3$ (возведение в куб) или $\sqrt[3]{x}$ прямо сейчас!»*, вот простая инструкция, как это сделать за 1 минуту:

### Пример: добавляем кнопку $x^3$ (возведение в куб)

#### Шаг 1. Создай новый класс операции в папке `src/operations/`
Создай файл `Cube.java`:
```java
package operations;

// Наследуем UnaryOperation, так как операция над одним числом
public class Cube extends UnaryOperation {
    @Override
    public String getName() {
        return "x³";
    }

    @Override
    public double calculate(double a) {
        return a * a * a; // или Math.pow(a, 3)
    }
}
```

#### Шаг 2. Добавь текст кнопки в массив в `src/Calculator.java`
В методе `buildScientificButtons()` (или `buildStandardButtons()`) просто допиши `"x³"` в список кнопок:
```java
String[] btns = {
    "π", "e", "CE", "C", "⌫",
    "x²", "x³", "1/x", "|x|", "mod", // <-- добавили x³
    ...
};
```

#### Шаг 3. Подключи операцию в обработчик
В методе `handleUnaryOperation(String opName)` добавь строчку:
```java
case "x³":
    op = new Cube();
    break;
```
**Всё!** Кнопка появится на экране, будет нажиматься, вычислять куб числа и записывать выражение в историю. Это наглядно показывает силу ООП: чтобы добавить новую функцию, мы просто добавляем новый класс и не переписываем старый код!
