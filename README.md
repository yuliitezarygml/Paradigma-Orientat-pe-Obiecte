# 🎓 Лабораторные работы по Объектно-Ориентированному Программированию (ООП)

> **Дисциплина:** Парадигмы программирования (Paradigme de programare)  
> **Раздел:** Объектно-ориентированное программирование на Java (POO Java)  
> **Автор:** Студент  
> **Язык разработки:** Java 17+ (OpenJDK 27)  
> **Операционная система:** macOS / Linux / Windows  

---

## 📑 Общая структура репозитория

В репозитории собраны 4 законченные лабораторные работы. Каждая работа находится в своей отдельной папке, полностью автономна, снабжена собственными автоматическими тестами, документацией и скриптом запуска в один клик (`./run.sh`).

```
unic/
├── README.md               # 📖 Главная документация ко всем лабораторным работам
├── .gitignore              # Исключение скомпилированных .class файлов и временных кэшей
│
├── lab1/                   # 🧮 Лабораторная работа 1: Графический Калькулятор (ООП)
│   ├── run.sh              # Скрипт компиляции и запуска
│   ├── README.md           # Подробное описание, ООП-архитектура, шпаргалка к защите
│   └── src/                # Исходный код (Operation, CalculatorEngine, UI)
│
├── lab2/                   # 📝 Лабораторная работа 2: Анализатор текста и частоты слов
│   ├── run.sh              # Скрипт компиляции и запуска
│   ├── README.md           # Описание алгоритмов, коллекций Map/Set, тесты
│   └── src/                # Исходный код (TextAnalyzer, WordFrequency, FileHandler)
│
├── lab3/                   # 🗄️ Лабораторная работа 3: База данных и поисковая система
│   ├── run.sh              # Скрипт компиляции и запуска
│   ├── README.md           # Архитектура CRUD, фильтрация, сортировка, тесты
│   └── src/                # Исходный код (EntityManager, SearchEngine, Storage)
│
└── lab4/                   # 🌐 Лабораторная работа 4: Интернет-браузер (WebKit)
    ├── run.sh              # Скрипт запуска и тестирования (./run.sh --test)
    ├── README.md           # Описание движка WebKit, вкладок, закладок, истории
    ├── favorites.txt       # Файл сохраненных закладок
    ├── lib/javafx-sdk/     # Локальный SDK JavaFX (WebKit WebEngine)
    └── src/                # Модульный код (TabBar, BrowserTab, NavigationBar и др.)
```

## 🚀 Быстрый запуск любой лабораторной работы

Каждая лабораторная работа запускается одной простой командой из терминала:

### 🧮 Лабораторная 1: Графический калькулятор
```bash
cd lab1 && ./run.sh
```
* **Что делает:** Открывает графический калькулятор с поддержкой базовых (`+`, `-`, `*`, `/`) и расширенных операций (`sqrt`, `pow`, `+/-`, `1/x`), защитой от деления на ноль и историей вычислений.
* **Принципы ООП:** Интерфейсы, полиморфизм (каждая операция — отдельный класс), инкапсуляция движка вычислений.

---

### 📝 Лабораторная 2: Анализатор текста и частоты слов
```bash
cd lab2 && ./run.sh
```
* **Что делает:** Читает текстовые файлы, анализирует частоту слов, ищет палиндромы, вычисляет статистику (уникальные слова, длинные слова, знаки препинания) и строит частотный словарь.
* **Принципы ООП и алгоритмы:** Использование коллекций Java Collections Framework (`HashMap`, `TreeMap`, `HashSet`), регулярные выражения, чтение файлов через `BufferedReader`.

---

### 🗄️ Лабораторная 3: База данных и поисковая система
```bash
cd lab3 && ./run.sh
```
* **Что делает:** Система управления записями (CRUD: создание, чтение, обновление, удаление) с многокритериальным поиском, сортировкой и сохранением базы данных на диск.
* **Принципы ООП:** Модель сущностей (Entity-Data model), разделение на слои (Presentation, Service, Repository), сериализация/десериализация.

---

### 🌐 Лабораторная 4: Интернет-браузер на движке WebKit
```bash
cd lab4 && ./run.sh
```
Запуск автоматических тестов (без графического интерфейса):
```bash
cd lab4 && ./run.sh --test
```
* **Что делает:**
  * Полноценный современный веб-браузер с интерфейсом в стиле **Google Chrome / Safari**.
  * Движок **JavaFX `WebView` (WebKit)**: полноценно открывает **YouTube**, **Google**, Википедию, исполняет современный JavaScript и поддерживает стили CSS3.
  * **Вкладки в самом верху (TabBar):** открываются кнопкой `➕`, закрываются крестиком `×`, активная вкладка подсвечивается белым.
  * **Панель навигации (NavigationBar):** кнопки `⬅ ➡ 🔄 ⏹ 🏠`, поле адреса (Omnibox) с замочком `🔒`, умный поиск в Google при вводе обычного текста.
  * **Визуализация HTTP-запросов:** по центру экрана появляется стильная карточка с индикатором прогресса (`0% -> 100%`), отображающая стадии сетевого запроса (`HTTP GET`, `TLS Handshake`, `DOM Rendering`).
  * **Закладки (Favorites):** кнопка `⭐` прямо в строке адреса, панель закладок (Bookmarks Bar) под адресом, автоматическое сохранение в `favorites.txt`.
  * **История посещений (History):** журнал со списком всех посещенных сайтов и точным временем `[HH:mm:ss]`.
* **Принципы ООП:**
  * **Инкапсуляция:** `BrowserTab` прячет внутри детали WebEngine и стеков истории.
  * **Единственная ответственность (SRP):** код разделен на 10 коротких файлов (каждый 40–180 строк).
  * **Паттерн Наблюдатель (Observer / Listener):** передача событий загрузки и изменения заголовка через интерфейсы обратного вызова.

## 🛠️ Требования к окружению

1. **Java Development Kit (JDK):** версия 17 или выше (рекомендуется OpenJDK 21 или 27).
2. **Bash:** стандартный командный интерпретатор macOS/Linux.
3. Скрипты `run.sh` автоматически находят установленный Homebrew OpenJDK (`/opt/homebrew/opt/openjdk` или `/usr/local/opt/openjdk`).

## 🧪 Автоматическое тестирование

Во всех работах реализованы автоматические тесты для проверки корректности бизнес-логики:
* В каждой работе есть класс `Test...` (например `TestBrowser`), проверяющий ключевые сценарии: обработку граничных значений, сохранение файлов, парсинг данных.
* Тесты запускаются автономно в консоли и гарантируют отсутствие регрессий при изменениях кода.
